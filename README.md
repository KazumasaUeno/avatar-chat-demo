# avatar-chat-demo

ブラウザだけで動く「3D アバターと話す」デモです。

- 公開ページ: https://kazumasaueno.github.io/avatar-chat-demo/
- 開くとすぐアバターがあいさつします（文字はすぐ表示。ブラウザの制限で、声は画面を最初にクリック／キー入力したときに出ます）。
- 文字を入力して送信すると、アバターが返事を読み上げ（ブラウザ内蔵の音声合成・日本語）、話している間だけ口が動きます。
- **公開ページの返事は決まった文言です。AI にはつながっていません**（入力内容はどこにも送信されません）。AI に返事させるのは、下の「手元で AI と話す」の方法で開いたときだけです。
- 右上の歯車から、アバター（同梱 2 体／自分の VRM）・言語（日本語 / English）・声・話す速さ・背景色を変えられます。設定はこのブラウザにだけ保存され、読み込んだ VRM はどこにも送信しません。
- `viewer.html` はアバターの表示確認用ページです（ドラッグで回転）。

## 手元で AI と話す（ローカル専用）

1. このフォルダーに `.env.local` を作り、`OPENAI_API_KEY=sk-...` と書く（Git には入りません）。環境変数で渡してもかまいません。
2. `node local-server.mjs` を実行し、http://127.0.0.1:8765/ を開く（`PORT=8770` のように番号を変えられます）。

- 入力した文と直近の会話（最大 10 往復）が OpenAI に送られ、OpenAI の利用料がかかります。
- モデルは既定で `gpt-4.1-mini`。`OPENAI_MODEL` で変えられます。
- キーはサーバー側にだけあり、ブラウザへは渡しません。キーが無いときは決まった返事になります。

## 使っているもの
